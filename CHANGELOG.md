# Changelog

## Unreleased — repository refactor

- Split the original v3.8.3 AutoHotkey script into separately maintained modules for targeting, recognition, dispatch, trail rendering, native HUD/canvas, persistence, application detection, settings UI, and icons.
- Extracted the embedded preset icons as separately inspectable `.ico` files. The generated AutoHotkey icon data remains in its own source file for **identical runtime behavior**.
- Added a deterministic, parity-checked standalone builder.
- Added Python structure/integrity tests, safe AutoHotkey helper tests, Windows CI, bilingual documentation, and an MIT license file.
- **No deliberate runtime/GUI/configuration/gesture changes.** A fully equivalent standalone file is generated by the builder.

## v3.8.3 — original baseline

- Lower-latency target activation using `SetWinDelay(0)`.
- Cursor-under-window targeting from v3.8.2.
- Custom system tray and GUI icons, gesture-specific colors, fast pixel recoloring, sensitivity/wheel/app settings, and tiled trails retained.
